# SniperThink Strategy Section

This project is a React-based implementation of the "How SniperThink Works" section.

## Features

- React Functional Components
- Dynamic rendering of strategy steps
- Scroll animations using Framer Motion
- Scroll progress indicator
- Backend API using Node.js and Express
- Async request handling
- Responsive UI

## Tech Stack

- React
- Framer Motion
- Node.js
- Express
